## Capability gaps

`RENDERED_SOURCE_REQUIRED` is **not implemented** and is not scheduled in M3.4.
It names a future capability, not a missing parser bug: the fetcher retrieves
served bytes, and a page whose records exist only after client-side execution
cannot be read by it. Adding it would mean a headless renderer in the ingest
path, which is a scope and trust decision beyond this phase. Until then the
affected targets are recorded as `null` rather than guessed at.

## Limitations

- External third-party branch coverage is **zero**. No verified public source
  supplies MFI branch-directory rows, and none is fabricated to fill the gap.
- `listBranches()` in the repository adapters is still an empty stub, as are
  `listFinancials()` and `listDocuments()` beside it. The branch projection is
  proven end to end against SQLite by `smoke:branch-lifecycle`, but no D1 read
  path serves it yet.
- A district correction currently produces a new branch identity rather than
  superseding in place, because geography is part of the identity key. This is
  a recorded identity decision, not a defect, and it is asserted as current
  behaviour by `L3.11`.
- Lint carries pre-existing errors in `.cjs` build scripts and
  `scripts/smoke-ingest-fixtures.ts`. None are in M3.4 code.
